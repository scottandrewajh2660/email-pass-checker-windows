## Overview

Email Pass Checker Utility gives Windows users a local way to inspect structured email and password lists. The application reads standard TXT and CSV files, evaluates email and password formats, finds duplicate records, and arranges data for more convenient analysis.

It is suited to audits involving large local datasets. Progress information is shown while processing, and domain grouping, user-defined regex rules, session history, and CSV or TXT output help users examine and retain the results of each run.

---

## Key Capabilities

- Load bulk data from TXT or CSV sources
- Check email structure and password formatting
- Locate duplicate records during local analysis
- Organize records according to email domain
- Follow processing activity from a live progress dashboard
- Create CSV or TXT reports from the results
- Add custom regular-expression rules for filtering
- Reopen earlier sessions and choose between dark and light themes

## Settings and Rules

The application's settings and rule controls can be used to change validation preferences and filtering behavior. When the built-in checks are not suitable for a particular audit format, additional regex rules can be supplied.

Example configuration:

```text
Input format:       CSV
Email validation:   Enabled
Password checks:    Enabled
Duplicate scan:     Enabled
Domain grouping:    Enabled
Custom regex rules: Optional
Report format:      CSV or TXT
Theme:              Dark or Light
```

Previous local processing runs can be accessed through the application's session-history feature.

## Frequently Asked Questions

### Which files can be imported?

Bulk TXT and CSV lists are supported as input.

### What report formats are available?

The application can export findings as either CSV or TXT files.

### Is an internet connection needed?

The described validation and audit process is designed to run offline on the local computer.

### Can validation patterns be customized?

Yes. Custom regex filtering rules can be added when extra filtering is required.

### How do I find duplicate records?

Activate duplicate detection before processing. Matching records can then be examined in the audit results.

### Is session information saved?

Session history is provided so earlier processing sessions can be reviewed.

### Are there different visual themes?

Yes. Both dark and light theme choices are available.

### What can I check when importing a file fails?

Make sure the selected document is readable and uses TXT or CSV format. Check its structure, then try importing a smaller sample to help locate formatting problems.
